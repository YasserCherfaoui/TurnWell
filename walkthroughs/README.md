# TurnWell Technical Walkthroughs

This directory contains step-by-step architectural and implementation walkthroughs designed for learning and reference.

## Sections

- **[Backend Walkthroughs (`backend/`)](./backend/README.md)** — Numbered guides covering the NestJS modular monolith, Prisma multi-schema ORM, security, cryptography, auth pipeline, onboarding profile setup, and tests (`0001` through `0009`).
- **[Mobile Walkthroughs (`mobile/`)](./mobile/README.md)** — Numbered guides covering the Flutter mobile client, Riverpod state architecture, Liquid Glass design system, route guards, and screens (`0001` onwards).
