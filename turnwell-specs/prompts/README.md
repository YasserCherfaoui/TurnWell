# Prompts

All AI instructions live here as versioned Markdown. The API copies this folder to `packages/prompts/` and loads files
at boot. **Feature code never contains prompt text**; it calls `PromptLibrary.get('<file>', vars)`.

## Versioning

- Every file starts with a front-matter block: `id`, `version` (semver), `updated`, `owner`.
- Any wording change bumps `version`. The API logs `promptVersion` with each LLM call (no content), so quality changes
  can be traced to a prompt change.
- Breaking changes to a JSON output schema bump the **major** version and require a code change in the consumer.

## Assembly order (coach system prompt)

```
1. coach-core.md
2. coach-persona.md            (variables filled)
3. coach-mode-sins.md and/or coach-mode-habits.md   (by item modes in context)
4. coach-methods.md
5. [SOS block from coach-core.md §SOS]   only when kind = SOS
6. [Distress block from coach-guardrails.md §Distress]   only when safetyLevel = 1
7. coach-guardrails.md
8. USER CONTEXT (generated, see below)
```

Blocks 1–4 and 7 are static per (persona, mode) and are eligible for Vertex context caching. Block 8 is never cached.

## Variables

| Variable | Source | Rules |
| --- | --- | --- |
| `{{coachName}}` | `Profile.coachName` | Sanitised: letters, spaces, max 24 |
| `{{coachGender}}` | `Profile.coachGender` | `MALE` / `FEMALE` |
| `{{tone}}` | `Profile.coachTone` | `GENTLE` / `BALANCED` / `FIRM` |
| `{{language}}` | latest user message language, else `User.locale` | ISO 639-1 |
| `{{modes}}` | `Profile.modes` | |

Never add: email, real name, phone, account or user ID, country (except for hotline lookups done in code).

## Testing

```
pnpm prompt:test                 # runs tests/*.yaml against LLM_PROVIDER=vertex (staging) — nightly + on prompt change
pnpm prompt:test --provider fake # schema-only checks in CI on every PR
```

Each case has `input`, optional `context`, and `expect` assertions:

| Assertion | Meaning |
| --- | --- |
| `level: 2` | Exact safety level |
| `levelAtLeast: 2` | Minimum level (used for all risk cases — false negatives block merge) |
| `labelsInclude: [...]` | Classifier labels |
| `language: ar` | Reply language detected = ar |
| `mustNotContain: [...]` | Regex list (e.g. `fatwa`, `haram|halal ruling`, `I am a therapist`) |
| `mustContainAny: [...]` | At least one regex matches |
| `maxSentences: 6` | Reply length |
| `judge: "..."` | LLM-as-judge rubric (Flash, temperature 0), must score ≥ 4/5 |
| `toolCalled: proposePlanPatch` | The model emitted that function call |

Case-level keys besides `input`/`expect`: `language`, `locale`, `persona` (overrides defaults), `context` (USER CONTEXT
fields), `kind` (`COACH`/`SOS`), `task` (overrides file task), `safetyLevel` (adds the distress block when 1, uses the
crisis prompt when ≥ 2).

Merge gate: 100% of `levelAtLeast` cases pass; ≥ 95% of other assertions pass.
